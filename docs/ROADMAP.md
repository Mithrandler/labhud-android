# Roadmap

## 0.1 — first version (done)

Server side in labhud 0.2.0: pairing with a one-time QR code, a token per phone, `/api/v1` with
each card's state worked out on the server (so the phone never disagrees with the wall), and
ntfy notifications that open the app on their card.

The app: pairing, the unlock when it opens, home with problems first and pages as tabs, the
card's screen with charts and actions, the timeline, several servers, the widget, wall mode.

## Next

- Tested on real phones and tablets (a Pixel 6a as the wall first), then what that shows.
- Game servers' page natively (it is in wall mode today).
- The action's progress after "sent" (the wall follows it until done, the app does not yet).
- A Quick Settings tile; widget buttons for chosen actions.
- IzzyOnDroid, then F-Droid (no Google libraries already, so nothing stands in the way).
- Translations, when someone offers one.
